Report. Attach at least one \texttt{report\_sup.pdf} sheet, with additional
sheets as needed. See the forms README for full completion rules.

\begin{enumerate}[leftmargin=*,itemsep=0.15em,topsep=0.4em]
  \item Complete by hand in ink, without AI assistance, in English, Japanese,
        Traditional Chinese, or Simplified Chinese.
  \item Record every applicable value. Use \texttt{N/A} with a reason only when
        a field cannot apply; write the accurate value if no choice applies.
  \item Before review, give the complete report to the reviewer assigned under
        POLICY.md and the project GOVERNANCE.md.
  \item The PR author keeps the original for four months after merge or
        closure. During the first three months, the Project Maintainer may
        request delivery; the project shall pay all fees incurred by delivery.
        Failure to produce it may trigger governance review.
\end{enumerate}
